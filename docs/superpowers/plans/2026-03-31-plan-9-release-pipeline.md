# Release Pipeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Automated release pipeline that builds CLI + desktop binaries, publishes GitHub Releases, and updates a Homebrew tap — all triggered by a git tag push.

**Architecture:** `cargo-release` bumps versions and creates tags. A tag push triggers `.github/workflows/release.yml` which runs cargo-dist for CLI builds (3 targets) + Homebrew formula, and Tauri Action for the macOS desktop `.dmg` + Homebrew cask. Version is sourced from `[workspace.package] version` in root `Cargo.toml`.

**Tech Stack:** cargo-release, cargo-dist, tauri-apps/tauri-action, GitHub Actions, Homebrew

**Spec:** `docs/superpowers/specs/2026-03-31-release-pipeline-design.md`

- [ ] **Step 1: Create release.toml**

### Task 4: Pre-build Script for SPA Embed

The `ensemble` CLI embeds a React SPA via `build.rs`. This requires Node.js, pnpm, and a pre-generated `openapi.json`. Create a build-setup script that cargo-dist runs before `cargo build`.

**Files:**
- Create: `.github/build-setup.sh`
- Modify: `dist-workspace.toml` (add github-build-setup reference)

- [ ] **Step 1: Create the build-setup script**

Create `.github/build-setup.sh`:

```bash
#!/usr/bin/env bash
set -euo pipefail

# Pre-build setup for cargo-dist CI.
# Installs Node/pnpm and generates openapi.json so that
# ensemble-cli's build.rs can embed the SPA.

UI_DIR="crates/ensemble-ui/src-ui"

# Install Node.js 22
echo "==> Installing Node.js 22"
curl -fsSL https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
export NVM_DIR="$HOME/.nvm"
[ -s "$NVM_DIR/nvm.sh" ] && . "$NVM_DIR/nvm.sh"
nvm install 22
nvm use 22

# Install pnpm via corepack
echo "==> Enabling corepack + pnpm"
corepack enable
corepack prepare pnpm@latest --activate

# Generate openapi.json (required before cargo build)
echo "==> Generating openapi.json"
cargo test -p ensemble-core --test openapi_spec write_openapi_spec -- --ignored

# Install frontend dependencies
echo "==> Installing frontend dependencies"
cd "$UI_DIR"
pnpm install --frozen-lockfile
cd -

echo "==> Build setup complete"
```

- [ ] **Step 2: Make the script executable**

```bash
chmod +x .github/build-setup.sh
```

- [ ] **Step 3: Reference the script in dist-workspace.toml**

Add the `github-build-setup` field to `dist-workspace.toml` under `[dist]`:

```toml
[dist]
github-build-setup = ".github/build-setup.sh"
```

This tells cargo-dist to run this script before each build job in the generated GitHub Actions workflow.

- [ ] **Step 4: Commit**


### Task 5: Tauri Desktop Build Job

Add the Tauri desktop build to the release workflow. This runs in parallel with cargo-dist's CLI builds, produces a signed `.dmg`, and uploads it to the GitHub Release.

**Files:**
- Modify: `.github/workflows/release.yml`

- [ ] **Step 1: Add the Tauri build job to release.yml**

Add the following job to `.github/workflows/release.yml`. Place it at the same level as the other jobs. It should run in parallel with cargo-dist builds (no `needs:` dependency on cargo-dist jobs), but it does need the release to exist first — cargo-dist's plan job typically creates the release, so add `needs: [plan]` (where `plan` is the cargo-dist plan job name — check the generated workflow for the exact name).

```yaml
  build-tauri:
    name: Build Tauri Desktop (macOS aarch64)
    needs: [plan]
    if: ${{ !fromJson(needs.plan.outputs.val).announcement_is_prerelease || fromJson(needs.plan.outputs.val).publish_prereleases }}
    runs-on: macos-latest
    permissions:
      contents: write
    steps:
      - uses: actions/checkout@v5

      - uses: dtolnay/rust-toolchain@stable
        with:
          targets: aarch64-apple-darwin

      - uses: Swatinem/rust-cache@v2

      - uses: pnpm/action-setup@v5
        with:
          package_json_file: crates/ensemble-ui/src-ui/package.json

      - uses: actions/setup-node@v6
        with:
          node-version: 22
          cache: pnpm
          cache-dependency-path: crates/ensemble-ui/src-ui/pnpm-lock.yaml

      - name: Install frontend dependencies
        run: pnpm install --frozen-lockfile
        working-directory: crates/ensemble-ui/src-ui

      - name: Generate OpenAPI spec
        run: cargo test -p ensemble-core --test openapi_spec write_openapi_spec -- --ignored

      - name: Generate frontend API client
        run: pnpm run codegen:client
        working-directory: crates/ensemble-ui/src-ui

      - name: Build frontend
        run: pnpm run build
        working-directory: crates/ensemble-ui/src-ui

      - uses: tauri-apps/tauri-action@v0
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          APPLE_CERTIFICATE: ${{ secrets.APPLE_CERTIFICATE }}
          APPLE_CERTIFICATE_PASSWORD: ${{ secrets.APPLE_CERTIFICATE_PASSWORD }}
          APPLE_SIGNING_IDENTITY: ${{ secrets.APPLE_SIGNING_IDENTITY }}
          APPLE_ID: ${{ secrets.APPLE_ID }}
          APPLE_TEAM_ID: ${{ secrets.APPLE_TEAM_ID }}
          APPLE_PASSWORD: ${{ secrets.APPLE_PASSWORD }}
        with:
          tagName: ${{ github.ref_name }}
          releaseName: ${{ github.ref_name }}
          releaseBody: ""
          releaseDraft: false
          prerelease: false
          tauriScript: cargo
          args: --target aarch64-apple-darwin
          projectPath: crates/ensemble-desktop
```

Note: The `tauri-apps/tauri-action` will upload the `.dmg` to the existing GitHub Release that cargo-dist created.

### Task 6: Homebrew Cask Update Job

After the Tauri build completes, update the cask file in the Homebrew tap.

**Files:**
- Modify: `.github/workflows/release.yml`

- [ ] **Step 1: Add the cask update job to release.yml**

Add this job after the `build-tauri` job:

```yaml
  update-homebrew-cask:
    name: Update Homebrew Cask
    needs: [build-tauri]
    runs-on: ubuntu-latest
    permissions:
      contents: read
    steps:
      - name: Get release version
        id: version
        run: echo "version=${GITHUB_REF_NAME#v}" >> "$GITHUB_OUTPUT"

      - name: Download .dmg from release
        env:
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        run: |
          gh release download "${{ github.ref_name }}" \
            --repo "${{ github.repository }}" \
            --pattern "*.dmg" \
            --dir ./artifacts

      - name: Compute SHA256
        id: sha
        run: |
          DMG_FILE=$(ls ./artifacts/*.dmg | head -1)
          DMG_NAME=$(basename "$DMG_FILE")
          SHA=$(shasum -a 256 "$DMG_FILE" | awk '{print $1}')
          echo "sha256=$SHA" >> "$GITHUB_OUTPUT"
          echo "dmg_name=$DMG_NAME" >> "$GITHUB_OUTPUT"

      - name: Update cask in tap
        env:
          TAP_TOKEN: ${{ secrets.HOMEBREW_TAP_TOKEN }}
        run: |
          VERSION="${{ steps.version.outputs.version }}"
          SHA256="${{ steps.sha.outputs.sha256 }}"
          DMG_NAME="${{ steps.sha.outputs.dmg_name }}"
          REPO="${{ github.repository }}"
          TAG="${{ github.ref_name }}"

          cat > ensemble-desktop.rb << CASK
          cask "ensemble-desktop" do
            version "${VERSION}"
            sha256 "${SHA256}"

            url "https://github.com/${REPO}/releases/download/${TAG}/${DMG_NAME}"
            name "Ensemble"
            desc "Multi-agent pipeline orchestrator"
            homepage "https://github.com/${REPO}"

            depends_on arch: :arm64

            app "Ensemble.app"
          end
          CASK

          # Clone the tap, update the cask, push
          git clone "https://x-access-token:${TAP_TOKEN}@github.com/chrisbanes/homebrew-tap.git" tap
          mkdir -p tap/Casks
          cp ensemble-desktop.rb tap/Casks/ensemble-desktop.rb
          cd tap
          git config user.name "github-actions[bot]"
          git config user.email "github-actions[bot]@users.noreply.github.com"
          git add Casks/ensemble-desktop.rb
          git commit -m "Update ensemble-desktop cask to ${VERSION}"
          git push
```
