## Interfaces for S03/S04

`StandaloneService.start/stop/submit/list` is the bootstrap and command seam.
`submit(workId, prompt, workspace, previousWorkId?)` is explicit, never a
scheduler: one immutable work ID permits one submission, and a follow-up requires
a completed prior binding in the same workspace. `ExecutionState` owns the
SQLite v3 intent/binding/hold rows; `CodexRuntime` owns authenticated App Server
stdio, selected policy, terminal events and denial responses. The `Runtime`
interface allows deterministic fault injection. Shared schema/bootstrap edits
remain in this S02 commit; S03/S04 can build their admission and command paths
above these seams without using the old prototype database or BB host interface.
