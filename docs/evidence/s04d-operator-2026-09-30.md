## Private HTTPS proof from the fixture host

The #694 gate requires a passing run through a disposable Tailscale HTTPS route
to a local operator fixture. This run originates on the same Mac as the fixture
and uses its canonical Tailscale HTTPS URL. It proves the private HTTPS and
browser boundary from that host; it does not establish reachability from a
separate device.

### Earlier no-fixture attempt

The extended `test/s04c/private-access.mjs` was invoked with the explicit
`--live` flag while `ENSEMBLE_TEST_HTTPS_ORIGIN`,
`ENSEMBLE_TEST_PROJECT_ID`, and `ENSEMBLE_TEST_PRIVATE_MARKER` were unset. It
returned exit status `2` and:

```text
Private-access proof needs an explicit HTTPS fixture
```

A read-only fixture check found `tailscale serve status --json` was `{}`. At
that time, the requested route
`tailscale serve --bg --yes http://127.0.0.1:18794` was rejected by automatic
review because it exposes the local fixture to the tailnet. Chris later
explicitly authorized temporary use of that route. This earlier invocation
remains an unrun proof, not a pass or waiver. The test does not create or mutate
Tailscale Serve configuration.

### Earlier authorized attempt (failed)

`65cfceea32c66806b0a596374ef3f00039d3aa80` with the approved temporary Serve

to `4/2`. The authenticated Runtime view and read-only SQLite query confirmed
the final `4/2`. This verified fixture-capacity restoration only. The route
owner later closed Serve and verified status `{}`; the listener and fixture
were removed.
