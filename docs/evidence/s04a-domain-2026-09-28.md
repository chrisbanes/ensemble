## Scope limits and handoff

The `domain_schema` migration, `DomainCommands`, `DomainStore` read and admission methods, and `LocalOperatorUi` are described in [the S04a boundary](../design/s04a-command-boundary.md). The operator HTTP adapter listens only on loopback when explicitly started; it is a minimal local surface without the #703 login. These fixtures do not prove remote UI, live TypeSafe decisions, the #691 scheduler, #690 workspaces, #693 result delivery, or live GitHub dependency reads. Routing operation persistence and pending assignment creation are atomic, but execution admission and lead wakeups remain downstream. Existing S02 ownership and uncertainty holds are preserved.
